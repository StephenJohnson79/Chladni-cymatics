方板共振与 Chladni 节线

Kirchhoff–Love 薄板方程

ρh ∂²w/∂t² + D∇⁴w = q(x,y,t)
D = Eh³ / [12(1 − ν²)]

ρ 为密度，h 为板厚，E 为杨氏模量，ν 为泊松比，D 为抗弯刚度，w 为横向位移。真实图案由几何、材料、边界条件、驱动位置和频率共同决定。

实时计算基（非自由边闭式解）

φₘₙ(x,y) = cos(mπx/a) cos(nπy/a)
ωₘₙ = [π²(m²+n²)/a²] √(D/ρh)
fₘₙ = F₀(m²+n²),   F₀ = 22.5 Hz

演示选择一组等效虚拟方板参数，以 F₀ 把无量纲模态缩放到可听频率。这里的余弦基对应 D’Alessio 论文用于校验数值法的辅助边界条件，并非真实自由边方板的精确模态。真实自由边问题没有已知简单闭式解，通常使用 Rayleigh–Ritz、有限差分或有限元法求解。

方板简并模态

Φₘₙ = [φₘₙ + βφₙₘ] / √(1+β²),   −1 ≤ β ≤ 1

第三个滑块控制无量纲系数 β。β = +1 与 β = −1 分别给出对称和反对称组合；β 接近 0 时偏向单一方向模态。

共振触发

Rₘₙ(f) = { [1−(f/fₘₙ)²]² + [f/(Qfₘₙ)]² }−1/2
|f − fₘₙ| ≲ fₘₙ / (2Q)

频率进入约半功率带宽时，对应模态占主导，节点线会稳定出现。Q 是无量纲品质因数：Q 越高，共振峰越窄、图案越清晰。

粒子迁移

Uᵢ = (|Σ RₘₙΦₘₙ|² − εᵢ)²,   d𝐫ᵢ/dt ∝ −∇Uᵢ + ξᵢ(t)

εᵢ 是每颗砂粒略有差异的微小停驻能量，使粒子停在有限宽度的节点带中，而不是无限压缩到同一条数学零线。算法还包含静摩擦式停驻、局部密度排斥和少量随机扰动；这是对砂粒节点聚集的实时可视化近似，不是完整的颗粒接触力学模型。

Square-plate resonance and Chladni nodal lines

Kirchhoff–Love thin-plate equation

ρh ∂²w/∂t² + D∇⁴w = q(x,y,t)
D = Eh³ / [12(1 − ν²)]

ρ is density, h plate thickness, E Young’s modulus, ν Poisson’s ratio, D flexural rigidity, and w transverse displacement. Real patterns depend jointly on geometry, material, boundary conditions, drive position, and frequency.

Real-time computational basis (not a free-edge closed form)

φₘₙ(x,y) = cos(mπx/a) cos(nπy/a)
ωₘₙ = [π²(m²+n²)/a²] √(D/ρh)
fₘₙ = F₀(m²+n²),   F₀ = 22.5 Hz

The demo chooses an equivalent virtual plate and uses F₀ to scale dimensionless modes into the audible range. The cosine basis is the auxiliary-boundary-condition solution used by D’Alessio to validate the numerical method; it is not the exact free-edge spectrum. No simple closed-form solution is known for the true free-edge problem, which is normally solved with Rayleigh–Ritz, finite-difference, or finite-element methods.

Degenerate square modes

Φₘₙ = [φₘₙ + βφₙₘ] / √(1+β²),   −1 ≤ β ≤ 1

The third slider controls the dimensionless coefficient β. β = +1 and β = −1 produce symmetric and antisymmetric combinations; values near zero favor one orientation.

Resonance condition

Rₘₙ(f) = { [1−(f/fₘₙ)²]² + [f/(Qfₘₙ)]² }−1/2
|f − fₘₙ| ≲ fₘₙ / (2Q)

A mode dominates when the drive enters approximately its half-power bandwidth. Q is dimensionless: a higher Q produces narrower resonance peaks and sharper patterns.

Particle migration

Uᵢ = (|Σ RₘₙΦₘₙ|² − εᵢ)²,   d𝐫ᵢ/dt ∝ −∇Uᵢ + ξᵢ(t)

Each grain has a slightly different small settling energy εᵢ, creating a finite-width nodal band instead of collapse onto one mathematical zero line. Static-friction-like settling, local density repulsion, and weak stochastic agitation are also included. This is a real-time visualization of nodal accumulation, not a complete granular-contact model.
